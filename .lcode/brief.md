写一份简短的晨间简报，三段，不要标题、不要 Markdown 表格：

**第一段：打招呼**
一句就好。用哪个问候语看环境块里 `Time` 后面括号里的时段，别自己从 HH:MM 推算：

| Time 括号里 | 问候语 |
|---|---|
| 早上（5:00–8:59） | 早上好 |
| 上午（9:00–11:59） | 上午好 |
| 中午（12:00–13:59） | 中午好 |
| 下午（14:00–17:59） | 下午好 |
| 晚上（18:00–22:59） | 晚上好 |
| 深夜（23:00–4:59） | 别说「晚上好」，用「这个点还没睡」这类 |

有点人味，但别肉麻，别写「很高兴为您服务」这种客服腔。

**第二段：今天衡阳的天气**
必须先用 search_web 查真实数据，不准凭记忆编。
要写清楚：温度区间、天气现象、风、要不要带伞。
数据要注明来源网站。多个来源打架时给出区间并说明「两个来源不一致」。

**第三段：今天可以干什么**
结合天气和星期几，给 2-3 条具体建议。要具体到能直接动手，
不要「多喝热水」「保持好心情」这种废话。例如：
- 下雨 + 工作日 → 通勤提前 15 分钟、带伞
- 晴 + 周末 → 适合出门走走 / 洗晒
- 温差大 → 洋葱式穿法
K 在折腾一个叫 lcode 的终端 AI 助手（就是你），如果今天没什么特别安排，
可以提一句「要不要继续弄 lcode」。

## 硬性要求

- 全文 200 字以内，手机通知一屏能看完。
- 天气查不到就直接说「今天天气没查到」，然后只给建议——**绝不编造天气数据**。
- 不写「希望对你有帮助」「祝你今天愉快」这类结尾套话。
- 不要调用 notify 工具（跑完系统会自动弹横幅），直接把简报作为回答正文。
