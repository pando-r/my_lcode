## 两组

## 盲评

- 答卷原件：`inbag/甲.md`、`inbag/乙.md`
- 送评副本：`inbag/A.md`（= 乙）、`inbag/B.md`（= 甲）
- 评分说明：`grader-prompt.md`
- 评分结果：`grade.md`

## 注意

两份答卷都是用同一个模型生成的，差别只来自"有没有 SKILL.md"。因此这测的是**Skill 提供的增量**，不是模型能力。
